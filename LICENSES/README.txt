License files shipped with ThermalIQ
===================================

This folder contains the full license texts for the third-party components
distributed with ThermalIQ 1.1.1. The component-to-license mapping is:

  Qt 6.7.3 (dynamic link)                  LGPL-3.0.txt
  FFmpeg 7.1.5 decoding libraries          LGPL-3.0.txt
  FFmpeg ffmpeg.exe (separate process)     GPL-3.0.txt
  MinGW-w64 GCC runtime libraries          GPL-3.0.txt + GCC-exception-3.1.txt
  Mesa 3D (opengl32sw.dll)                 MIT.txt
  Microsoft D3Dcompiler_47.dll             D3Dcompiler-NOTICE.txt
  SQLite (qsqlite.dll)                     Public domain, no license text required

The consolidated notice, including copyright statements, source locations,
build configurations and SHA-256 values, is THIRD-PARTY-NOTICES.txt in the
installation directory (one level above this folder).

The corresponding source for the LGPL and GPL components is provided in the
source-offer package for ThermalIQ 1.1.1. Source requests may be sent to:

  chinapeter2008@163.com

All license-facing texts are provided in English so that they can be compared
directly with the upstream license documents.
